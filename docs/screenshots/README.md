🔴 **캡처가 유일한 실행 증거다.** 배포 주소는 노트북이 꺼지면 닫히고, 실행 기록(`runs/`)은
저장소에 넣지 않는다. 그때 남는 것은 이 폴더의 이미지들뿐이다.

실패·재시도 화면도 함께 증명된다.

## 실패 화면을 다시 만들려면

`07-failure.png` 는 실패 주입을 켠 상태에서 찍었다. 다시 찍으려면 서버를 이렇게 띄운다.

```bash
FAULT_INJECT=search_empty,image_fail uv run uvicorn app.main:app --port 8765
```

켜져 있으면 화면 상단에 경고 배너가 뜬다. **숨기지 않는 것이 원칙이다** (`app/tools/faults.py`).
쓸 수 있는 값: `search_empty` `fetch_fail` `weather_fail` `image_fail` `line_fail`

이미 앱이 8765 에서 돌고 있으면 포트를 바꿔 따로 띄우면 된다 (`--port 8766`).

## 주의

- 배포 캡처는 **주소창이 보여야** 증거가 된다. 헤드리스 브라우저로 찍으면 주소창이 없다
- 파일명은 **영문·공백 없음**. 한글 파일명은 셸 명령에서 깨진다
- 개인정보·API 키·토큰이 화면에 노출되지 않았는지 확인하고 넣을 것
