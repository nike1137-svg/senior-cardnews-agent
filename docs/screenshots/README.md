# 결과물 캡처본

🔴 **제출 필수 항목이다.** 구글폼 제출은 GitHub 저장소 URL 하나이고,
그 안에 *"실제 결과물 캡처본 포함"* 이 요구된다. **캡처가 유일한 실행 증거다.**

## 지금 있는 것

| 파일 | 내용 | 무엇을 증명하나 |
|---|---|---|
| `01-start.png` | 주제 입력 화면 | 시작 지점 |
| `02-question.png` | **질문 대기 + 단계 진행바** | 🔴 사람 개입 지점 (평가 3·4번) |
| `05-cards.png` | 완성된 카드뉴스 5장 | 최종 결과물 |
| `06-dashboard.png` | 실행 기록 — 반복·도구·실패·토큰·비용 | 🔴 비용 대시보드 (평가 4번) |
| `08-deploy-browser.png` | **배포된 주소로 접속한 화면 (주소창 포함)** | 🔴 배포 증거 (평가 5번) |
| `08-deploy-runs.png` | 배포 주소의 실행 기록 화면 | 배포가 앱 전체에 걸림 |
| `09-full-run.png` | **전체 흐름 한 장** — 진행바·질문·카드·답변이력·실행로그·사용량 | 🔴 관찰 가능성 전부 |

`09-full-run.png` 안에 **실패한 도구 호출이 빨간 줄로** 들어 있어
실패·재시도 화면도 함께 증명된다.

## 아직 없는 것

|---|---|---|
| `07-failure.png` | 실패 주입을 켠 상태의 화면 | `FAULT_INJECT=search_empty,image_fail` 로 서버를 띄우면 상단에 경고 배너가 뜬다 |

## 주의

- 배포 캡처는 **주소창이 보여야** 증거가 된다. 헤드리스 브라우저로 찍으면 주소창이 없다
- 파일명은 **영문·공백 없음**. 한글 파일명은 셸 명령에서 깨진다
- 개인정보·API 키·토큰이 화면에 노출되지 않았는지 확인하고 넣을 것
